Ry
Mat, drikke, kultur, events

Ry is an unpretentious place for food, drinks, culture and events in the old industrial halls of Stavanger Øst. Meze from local produce, a stone oven, a concert or a quiz. Or just leave a drawing behind.

The identity is built on drawings: naive, funny, a bit pixelated. It's deliberately simple, so the people at Ry can make their own menus and posters with coloured paper, a template and an ordinary laser printer. This page is everything you need to do that.

01

Logo

The logo is a drawing, not a font. It also moves: the animated version can be used anywhere on screen. Use it in black or white only, always from the files below. Never redraw it, stretch it or add effects.

Typography

One typeface: A2Z Faucet. Ry sets it in capitals, mostly in Regular. Hierarchy comes from size and placement, not from mixing weights. Let the drawings be the loud part.

Install the OTF files on the computers that make menus and posters. The WOFF files are for the website.

04

Illustration

The drawings are the heart of Ry. Naive, a little silly, sketched by hand and then pixelated so they belong together. Everyone is invited to add new ones. The pixel effect, the type and the grid are what keep it all one family.

Ink

Adding a drawing of your own

  1. DrawBlack marker on white paper. Thick lines, simple shapes. Funny beats pretty.
  2. ScanScan or photograph it flat, in daylight, straight from above.
  3. PixelateRun it through the same pixel effect as the others. Studio Blunt can help.
  4. Use one colourOne ink from the palette on one of the paper colours. Never mix inks.

05

Menus and print

Menus change often, so they're made to be made at Ry. Open the template, change the text, print in black on coloured paper. Header line on top, dishes in a clear list with prices on the right, one drawing in a corner.

The Word template is an A4 page with the menu in a 140 × 297 mm strip on the left: print on A4, then trim to 140 mm. Install A2Z Faucet first and set the text styles to it; the template falls back to Arial.
